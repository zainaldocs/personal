Tentang Saya

Software engineer berdomisili di Jakarta dengan pengalaman lebih dari 8 tahun dalam membangun platform web berskala besar dan infrastruktur cloud.

Perjalanan saya di dunia rekayasa perangkat lunak dimulai dari rasa ingin tahu tentang bagaimana paket jaringan melintasi internet global. Sejak saat itu, saya berkesempatan bekerja dengan startup tahap awal hingga tim enginer berpengalaman di Asia Tenggara.

Saya mengosialisasi diri dalam arsitektur web full-stack, infrastruktur API, microservices Go/Rust, serta framework modern seperti React, Next.js, dan TypeScript. Saya sangat menyukai kesederhanaan, kode yang bersih, dan performa tinggi.

Di luar aktivitas pengkodean, saya menulis esai teknis, berkontribusi pada pustaka open-source, membaca buku filsafat, dan menyeduh kopi spesial.
